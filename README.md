# Drupal core DX improvements

Reveal.js slides (Vite 8 + pnpm) on developer quality-of-life improvements in Drupal core since 10.0.

- Slides live in `slides.md` (`---` between slides, `--` for vertical, `Note:` starts speaker notes).
- Side-by-side code uses the `.two-column` grid (see `src/style.css`).

```sh
pnpm install
pnpm dev      # http://localhost:8000
pnpm build    # outputs to dist/
```
